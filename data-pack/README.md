# data-pack · 你自己的资料目录

这个目录是**资料（真题 / 录音 / 词表）的固定落点**：把东西按下面的分类丢进来，
`npm run build:data` 就能一键生成题库，不需要再记路径。

> **只有这份 README、`pack.json` 和各分类目录的 `.gitkeep` 会进 Git。**
> 里面的 docx、pdf、mp3、csv、txt 全部被 `.gitignore` 挡住——
> 试题与录音的著作权归原权利人，它们留在你本机，不会被推到公开仓库，也不会进 npm 包。
> 想给资料做版本管理：把仓库设为 Private，或另建一个私有数据仓（见 `docs/data-pack.md`）。

## 分类

```
data-pack/
├─ 01 真题试卷/
│  └─ <考期>/<套>/<任意文件名>.docx          首选 .docx；也可 .pdf，或同名 .txt 纯文本卷
├─ 02 答案/
│  └─ YYYY年M月第N套_答案.txt               一套一份；也兼容 *_答案总表.csv
├─ 03 听力原文/
│  └─ YYYY年M月第N套_听力原文.txt            可选；没有就只能靠听
├─ 04 听力音频/
│  └─ YYYY年M月第N套_听力音频.mp3            可选；支持 .mp3 / .m4a / .aac
├─ 05 词汇/
│  ├─ 六级核心2500词.csv                     表头需含：单词、释义（音标 / 星级 / 频次 可选）
│  └─ 六级6000词汇.csv
├─ audio-tracks.json                         可选：听力分段表（按节跳听用）
└─ pack.json                                 可选：这份资料包的版本与来源记录
```

目录名前的 `01`–`05` 是识别依据，后面的名字可以随便改；`04` 与 `05` 谁在前都行，
构建按内容判断（有 `*.csv` 的是词汇目录，有音频的是音频目录）。

## 命名规则（认不出名字就没法自动归属）

| 东西 | 名字要能解析出 |
| --- | --- |
| 试卷 | 所在路径里要有 `2023年6月` 这样的考期，和 `第1套` 这样的套号 |
| 答案 / 原文 / 录音 | `YYYY年M月第N套`，例如 `2025年12月第2套_听力音频.mp3` |

## 加东西

```powershell
# 1) 放文件
#    新一套卷：  data-pack/01 真题试卷/2026年12月/第1套/整卷.docx
#    它的答案：  data-pack/02 答案/2026年12月第1套_答案.txt
#    它的录音：  data-pack/04 听力音频/2026年12月第1套_听力音频.mp3
#    新词表：    data-pack/05 词汇/你的新词表.csv（表头对齐现有的）

# 2) 先体检目录（几秒，不读卷面内容）
npm run check:pack

# 3) 再构建题库（默认读 data-pack/，写到 ~/.dsh/dsh-cet6/data）
npm run build:data

# 4) 确认 problems 为空
npm run check:data
```

第 3 步默认就是从 `data-pack/` 读，不用写 `--src`；想用别处的资料再显式指定：
`npm run build:data -- --src "D:/别的目录"`。

## pack.json

构建不依赖它，只是给你自己记账用：

```json
{
  "name": "cet6-2023-2026",
  "updatedAt": "2026-11-07",
  "source": "自购真题册 / 听力音频",
  "periods": ["2023-06", "2023-12", "2024-06", "2024-12", "2025-06", "2025-12", "2026-06"],
  "note": "仅个人学习使用，不公开分发"
}
```

## 常见报错

- **`找不到 01 试卷目录`**：目录名开头不是 `01`，或东西放到了别的层级。
- **`没有答案`**：`02 答案/` 里缺这一套，或文件名解析不出考期/套号。
- **`录音归属靠推定`**：有录音但没配套听力原文，界面上会标「录音按套号推定」，自己听一遍确认。
- **`词表被忽略`**：`05 词汇/` 里的 CSV 表头没有「单词」或「释义」列。
